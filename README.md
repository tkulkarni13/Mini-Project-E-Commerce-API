# Mini-Project: E-Commerce API
This API allows users to manage data in an e-commerce setting. The user can access API request relating to customer management, customer account management, product management, and orders management. For each of these categories, there are routes to create new datapoints, read datapoints, update datapoints, and delete datapoints. The data is stored in a SQL database using Flask-SQLAlchemy for integration. In addition, there are addition routes with bonus funcionality if needed by the user. There is capability to view and manage stock levels of individuals products, and an automatic restocking function when stock is low. A user could also view the complete order history of a specific customer, or calculate the total price of an order.
